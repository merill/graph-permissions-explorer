ResourcePolicyConfiguration.ReadWrite.All

Allows the app to read and write the tenant-wide resource policy configuration, including setting the privileged-read app ID used by all fetch() calls during policy evaluation, on behalf of the signed-in user.

Merill's Note

For an app to access data in Microsoft Graph, the user or administrator must grant it the permissions it needs. This article lists all the Microsoft Graph APIs and your tenant data that can be accessed by the application (vendor/developer) if you consent to the ResourcePolicyConfiguration.ReadWrite.All permission.

If you need to create an audit report of the permissions granted to all the apps in your tenant, you can run the Export-MsIdAppConsentGrantReport command. See How To: Run a quick OAuth app audit of your tenant

Resources

Granting this permission allows the calling application to access (and/or update) the following information in your tenant.

  • privilegedReadSetting
  • resourcePolicyConfiguration

Graph reference: privilegedReadSetting

Property Type Description
appId String The customer-owned application's client ID used for fetchAsPolicy() calls. Setting this value activates privileged reads for the tenant. When absent or null, privileged reads are disabled and fetchAsPolicy() fails with HTTP 403.

Graph reference: resourcePolicyConfiguration

Property Type Description
lastModifiedDateTime DateTimeOffset The date and time the object was last modified, in ISO 8601 format and UTC. Read-only.
privilegedReadSetting privilegedReadSetting The customer-owned application configuration for fetchAsPolicy().
