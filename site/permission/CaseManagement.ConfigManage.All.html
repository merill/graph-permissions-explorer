CaseManagement.ConfigManage.All

Allows the app to create, read, update, and delete case management configuration, such as SLA policies, on behalf of the signed-in user.

Merill's Note

For an app to access data in Microsoft Graph, the user or administrator must grant it the permissions it needs. This article lists all the Microsoft Graph APIs and your tenant data that can be accessed by the application (vendor/developer) if you consent to the CaseManagement.ConfigManage.All permission.

If you need to create an audit report of the permissions granted to all the apps in your tenant, you can run the Export-MsIdAppConsentGrantReport command. See How To: Run a quick OAuth app audit of your tenant

Resources

Granting this permission allows the calling application to access (and/or update) the following information in your tenant.

  • caseTypeConfiguration
  • slaPolicyCriteriaBlock
  • slaPolicyDefinition
  • slaPolicyRecalculateCondition
  • slaPolicyTimer

Graph reference: caseTypeConfiguration

Property Type Description
defaultStatusId String The id of the top-level status that a new case of this type starts in.
displayName String The human-readable label of the case type.
id String The unique identifier of the case type. The value is the case type name: genericCase, incidentCase, or exposureCase. Read-only.

Graph reference: slaPolicyCriteriaBlock

Property Type Description
conditions microsoft.graph.security.caseManagement.slaPolicyConditionBase collection The leaf conditions or nested groups evaluated by this block. The maximum nesting depth is two.
logicalOperator microsoft.graph.security.caseManagement.slaPolicyLogicalOperator The logical operator that combines the conditions. The possible values are: and, or, unknownFutureValue.

Graph reference: slaPolicyDefinition

Property Type Description
createdBy String The identifier of the identity that created the policy. Read-only. Inherited from caseManagementEntity.
createdDateTime DateTimeOffset The date and time when the policy was created, in ISO 8601 format and UTC. Read-only. Inherited from caseManagementEntity.
description String The description of the policy. Maximum length: 5,000 characters.
displayName String The display name of the policy. Must be unique across the tenant, using a case-insensitive comparison. Maximum length: 150 characters.
exitCriteria microsoft.graph.security.caseManagement.slaPolicyCriteriaBlock The condition that removes a case from the policy's scope.
id String The unique, server-generated identifier of the policy. Read-only. Inherited from caseManagementEntity.
isActive Boolean Whether the policy is actively evaluated. Inactive policies are excluded from new case evaluations. The default value on creation is true.
lastModifiedBy String The identifier of the identity that last modified the policy. Read-only. Inherited from caseManagementEntity.
lastModifiedDateTime DateTimeOffset The date and time when the policy was last modified, in ISO 8601 format and UTC. Read-only. Inherited from caseManagementEntity.
pauseCriteria microsoft.graph.security.caseManagement.slaPolicyCriteriaBlock The condition that pauses the timer while a case matches it.
recalculateCondition microsoft.graph.security.caseManagement.slaPolicyRecalculateCondition The settings that control whether elapsed time resets when the policy is recalculated.
setCriteria microsoft.graph.security.caseManagement.slaPolicyCriteriaBlock The condition a case must match to enter the policy's scope. When omitted, the policy applies to all cases of its owning case type. The maximum nesting depth is two.
timers microsoft.graph.security.caseManagement.slaPolicyTimer collection The embedded warning and breach timers, evaluated in **o

Graph reference: slaPolicyRecalculateCondition

Property Type Description
shouldResetTime Boolean Whether elapsed time resets when the policy is recalculated, for example, when a case reenters its scope.

Graph reference: slaPolicyTimer

Property Type Description
breachThresholdInMinutes Int32 The elapsed time in minutes after which the timer is considered breached. Required when supplying a timer.
filters microsoft.graph.security.caseManagement.slaPolicyCriteriaBlock The condition that a case must match for this timer to apply. Required when isDefault is false. Omit this property for the default timer.
isDefault Boolean Whether this timer is the fallback when no other timer's filters match. Required when supplying a timer. Exactly one timer per policy must have a value of true.
order Int32 The evaluation order among the policy's timers, lowest first. Required when supplying a timer.
policyTimerId String The server-generated identifier for the timer. Computed on creation and immutable thereafter. Read-only. Omit this property from request bodies.
warningThresholdInMinutes Int32 The elapsed time in minutes after which an early warning is raised.
