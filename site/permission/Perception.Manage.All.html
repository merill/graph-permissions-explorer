Perception.Manage.All

Allows the app to read Agentic Security resources, create sessions and request cancellation on behalf of the signed-in user, subject to the user's access.

Merill's Note

For an app to access data in Microsoft Graph, the user or administrator must grant it the permissions it needs. This article lists all the Microsoft Graph APIs and your tenant data that can be accessed by the application (vendor/developer) if you consent to the Perception.Manage.All permission.

If you need to create an audit report of the permissions granted to all the apps in your tenant, you can run the Export-MsIdAppConsentGrantReport command. See How To: Run a quick OAuth app audit of your tenant

Resources

Granting this permission allows the calling application to access (and/or update) the following information in your tenant.

  • agentRun
  • agentRunFailureInfo
  • investigationInput
  • investigationOutput
  • investigationSession
  • playbookDefinition

Graph reference: agentRun

Property Type Description
agent agentInfo The embedded description of the agent that performed this run. Read-only.
completedDateTime DateTimeOffset The UTC date and time when the run completed successfully, in ISO 8601 format. Absent otherwise. Read-only.
createdDateTime DateTimeOffset The UTC date and time when the resource was created, in ISO 8601 format. Read-only.
durationInMilliseconds Int64 The elapsed time from creation to successful completion, in milliseconds. Absent otherwise. Read-only.
failureInfo agentRunFailureInfo The run-level failure details, when available. Read-only.
id String The unique, read-only identifier of the resource.
initiatedBy investigationIdentitySet The initiating principals recorded by the service, when available. Read-only. This property doesn't select an execution identity.
lastModifiedDateTime DateTimeOffset The UTC date and time when the resource was last updated, in ISO 8601 format. Read-only.
startedDateTime DateTimeOffset The UTC start timestamp, in ISO 8601 format. Currently reflects creation time, not a distinct execution-start measurement. Read-only.
status longRunningOperationStatus The service-computed processing status. The possible values are: notStarted, running, succeeded, failed, unknownFutureValue. A canceled execution has failed status and canceled statusDetail. A request for input has running status and pendingInput statusDetail. Read-only.
statusDetail String Additional processing detail, including pendingInput or canceled, when the status alone doesn't describe the source lifecycle. Read-only. Doesn't support $filter.

Graph reference: agentRunFailureInfo

Property Type Description
errorType String The error classification, when available.
message String The human-readable failure detail, when available.

Graph reference: investigationInput

Property Type Description
displayName String The display name populated by the service when available. Read-only.
id String The stable, service-generated input identifier, unique within its containing session. Read-only. Don't supply it on deep insert.
kind investigationInputType The input kind. Required when creating a session and immutable afterward. The possible values are: defenderIncidentId, defenderAlertId, defenderThreatIntelligenceId, azureSubscriptionId, azureIdentityId, keyword, unknownFutureValue. The selected playbook must accept the kind. Don't supply unknownFutureValue.
value String The type-specific resource identifier or keyword text. Required when creating a session and immutable afterward.

Graph reference: investigationOutput

Property Type Description
content Stream The output bytes, retrieved through /security/agenticSecurity/sessions/{session-id}/outputs/{output-id}/content. The stream isn't inline in the metadata response. Read-only.
id String The stable, opaque stored-file identifier, unique within its containing session. Read-only.
kind investigationOutputType The output category. The possible values are: summary, artifact, unknownFutureValue. Both summary text and artifact bytes are retrieved through the authenticated content route. Read-only.

Graph reference: investigationSession

Property Type Description
createdDateTime DateTimeOffset The UTC date and time when the resource was created, in ISO 8601 format. Read-only.
displayName String The session name generated by the service. Read-only.
id String The unique, read-only identifier of the resource.
initiatedBy investigationIdentitySet The initiating principals recorded by the service, when available. Read-only. This property doesn't select an execution identity.
lastModifiedDateTime DateTimeOffset The UTC date and time when the resource was last updated, in ISO 8601 format. Read-only.
status longRunningOperationStatus The service-computed processing status. The possible values are: notStarted, running, succeeded, failed, unknownFutureValue. A canceled execution has failed status and canceled statusDetail. A request for input has running status and waitingForInput statusDetail. Read-only. Supports $filter (eq, or, in) when listing sessions.
statusDetail String Additional processing detail, including waitingForInput or canceled, when the status alone doesn't describe the source lifecycle. Read-only. Doesn't support $filter. For the session lifecycle combinations, see Get agentic session.
tags String collection The service-generated tags for the session. Read-only. Can't be supplied when creating a session.

Graph reference: playbookDefinition

Property Type Description
acceptedInputTypes investigationInputType collection The input kinds accepted by this playbook. The possible values are: defenderIncidentId, defenderAlertId, defenderThreatIntelligenceId, azureSubscriptionId, azureIdentityId, keyword, unknownFutureValue. unknownFutureValue isn't a valid value when creating a session. Read-only.
description String The description of the work performed by the playbook. Read-only.
displayName String The human-readable name of the playbook. Read-only.
id String The service-generated, persisted GUID-string identifier of the playbook definition. Read-only.
uniqueName String The immutable, unique catalog name, such as investigate-incident. Distinct from **i
