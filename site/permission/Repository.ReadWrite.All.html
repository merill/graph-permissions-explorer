Repository.ReadWrite.All

Allows the app to read and manage connected security content source-control repositories, including connecting and disconnecting repositories, on behalf of the signed-in user.

Merill's Note

For an app to access data in Microsoft Graph, the user or administrator must grant it the permissions it needs. This article lists all the Microsoft Graph APIs and your tenant data that can be accessed by the application (vendor/developer) if you consent to the Repository.ReadWrite.All permission.

If you need to create an audit report of the permissions granted to all the apps in your tenant, you can run the Export-MsIdAppConsentGrantReport command. See How To: Run a quick OAuth app audit of your tenant

Graph reference: contentManagementRepository

Property Type Description
contentTypes microsoft.graph.security.contentManagement.repositoryContentType collection Content kinds this repository is configured to deploy. The possible values are: customDetection, unknownFutureValue, defenderWorkbook. Use the Prefer: include-unknown-enum-members request header to get defenderWorkbook.
deploymentIdentity microsoft.graph.security.contentManagement.deploymentIdentity Bring-your-own deployment identity used for deployment. Optional; when omitted the platform-managed identity path is used. Provide a service principal or a managed identity. Immutable after connecting.
deploymentScope microsoft.graph.security.contentManagement.deploymentScope Optional Azure deployment scope, immutable after connecting the repository.
description String Optional description of the connection.
displayName String Human-readable name of the connection. Supports $filter (eq, ne) and $orderby.
id String A unique identifier for this resource. Inherited from entity. Supports $filter (eq, ne).
lastDeploymentInfo microsoft.graph.security.contentManagement.repositoryDeploymentInfo Status of the most recent deployment from this repository. Read-only.
pullRequest microsoft.graph.security.contentManagement.repositoryPullRequest The setup pull request opened for this connection, when applicable. Read-only.
repoType microsoft.graph.security.contentManagement.repositoryType Source-control provider for this repository. Immutable after connecting. Supports $filter (eq, ne). The possible values are: gitHub, azureDevOps, unknownFutureValue.
servicePrincipal microsoft.graph.security.contentManagement.repositoryServicePrincipal Service principal / managed identity used by the connection. Read-only.
sourceLocation microsoft.graph.security.contentManagement.repositorySettings Location of the source repository (URL and branch).
systemData microsoft.graph.security.contentManagement.systemData Creation and last modification provenance. Read-only.
workloadIdentityFederation microsoft.graph.security.contentManagement.repositoryWorkloadIdentityFederation Workload identity federation details for the connection, when configured. Read-only.
