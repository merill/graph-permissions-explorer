ContentHub-Installed.Read.All

Allows the app to read which Content Hub security content packages and package-scoped content items your organization has installed and at what versions, on behalf of the signed-in user. Does not grant access to the published catalog or the ability to install, update, or remove installed content.

Merill's Note

For an app to access data in Microsoft Graph, the user or administrator must grant it the permissions it needs. This article lists all the Microsoft Graph APIs and your tenant data that can be accessed by the application (vendor/developer) if you consent to the ContentHub-Installed.Read.All permission.

If you need to create an audit report of the permissions granted to all the apps in your tenant, you can run the Export-MsIdAppConsentGrantReport command. See How To: Run a quick OAuth app audit of your tenant

Granting this permission allows the calling application to access (and/or update) the following information in your tenant.

  • contentPackage
  • installedContentItem
  • installedPackage

Graph reference: contentPackage

Property Type Description
author microsoft.graph.security.contentManagement.contentAuthor The package author. Inherited from contentPackageBase. Read-only. Supports $filter (eq, ne) on author/displayName.
categories microsoft.graph.security.contentManagement.contentCategories Publisher taxonomy for the package. Inherited from contentPackageBase. Read-only. Supports $filter (any) on categories/domains and categories/verticals.
contentProductId String ARM-facing product identifier of the package in Azure Marketplace and Azure Resource Manager, distinct from the version-stable id. Inherited from contentPackageBase. Read-only. Supports $filter (eq, ne).
dependencies Json Publisher-defined package prerequisites and bill-of-materials criteria as JSON. Returned on by-key reads; unavailable on collection reads even with $select. Read-only.
description String Plain-text description of the latest version, when supplied by the publisher. Inherited from contentPackageBase. Read-only.
descriptionHtml String Publisher-authored description of the latest version, including HTML markup. Callers that render this field must sanitize it as untrusted markup. Inherited from contentPackageBase. Read-only.
displayName String Display name of the latest version of the package. Read-only. Supports $filter (eq, ne) and $orderby.
firstPublishDateTime DateTimeOffset Date and time when the package was first published, in UTC. Null when unknown. Read-only. Supports $filter (eq, ne, gt, ge, lt, le) and $orderby.
icon String Publisher-authored icon reference for the package, when declared. Inherited from contentPackageBase. Read-only.
id String Stable identifier of the package across versions. Inherited from entity. Read-only. Supports $filter (eq, ne).
isDeprecated Boolean Indicates whether the package is deprecated in this catalog generation. Read-only. Supports $filter (eq, ne).
isFeatured Boolean Indicates whether the package is editorially promoted by the publisher. Read-only. Supports $filter (eq, ne).
isNew Boolean Indicates whether the package is marked as new by the publisher. Read-only. Supports $filter (eq, ne).
isPreview Boolean Indicates whether the latest version is a prerelease, as declared by the publisher. Read-only. Supports $filter (eq, ne).
kind String Package kind, such as Solution or Standalone. Open string defined by the publisher; null when no kind is declared. Read-only. Supports $filter (eq, ne).
lastPublishDateTime DateTimeOffset Date and time when the package was last published, in UTC. Null when unknown. Read-only. Supports $filter (eq, ne, gt, ge, lt, le) and $orderby.
mainTemplate Json Publisher-defined deployment template as a direct JSON object. Included by default on by-key reads; unavailable on collection reads even with $select. Read-only.
migratedToPackageId String Publisher-supplied identifier of the package that this package migrated to, when applicable. Read-only.
providers String collection Security providers for which the package delivers content. Inherited from contentPackageBase. Read-only. Supports $filter (any).
publisherDisplayName String Display name of the publishing organization. Inherited from contentPackageBase. Read-only. Supports $filter (eq, ne).
source microsoft.graph.security.contentManagement.contentPackageSource Publisher source information. Returned on by-key reads; unavailable on collection reads even with $select. Read-only.
support microsoft.graph.security.contentManagement.contentSupport Support contact and tier information for the package. Inherited from contentPackageBase. Read-only. Supports $filter (eq, ne) on support/tier and support/displayName.
version String Latest version of the package in the committed catalog generation. Read-only. Supports $filter (eq, ne) and $orderby.

Graph reference: installedContentItem

Property Type Description
contentProductId String ARM-facing product identifier of the installed content item. Read-only. Supports $filter (eq, ne).
id String Customer-facing Content Hub identifier of the content item, matching the catalog contentItem id and globally unique across packages. Inherited from entity. Read-only. Supports $filter (eq, ne).
installedDateTime DateTimeOffset Date and time when the tenant first installed this content item, in UTC. Preserved across content and package version upgrades; null when unknown. Read-only. Supports $filter (eq, ne, gt, ge, lt, le) and $orderby.
kind String Content kind, such as AnalyticsRule, Workbook, or HuntingQuery. Open string defined by the publisher. Read-only. Supports $filter (eq, ne).
lastModifiedDateTime DateTimeOffset Date and time when this content installation last changed, in UTC. Null when unknown. Read-only. Supports $filter (eq, ne, gt, ge, lt, le) and $orderby.
packageId String Owning package reference recorded on the installed content item payload (for example, the owning package's contentProductId). Note that the canonical {packageId} route key on /security/contentManagement/installedPackages/{packageId} is the parent installedPackage resource's id. Read-only. Supports $filter (eq, ne).
packageVersion String Version of the owning package under which this content item is installed. Supports $filter (eq, ne).
version String Installed version of the content item. Supports $filter (eq, ne) and $orderby.
